# Bundled source origins

These sources are included as ordinary files so a fresh checkout retains the
local Qt 6 modifications and all populated dependencies. The revisions below
identify the upstream bases, not the modified snapshot. Original license files
are retained in each source tree. Nested Git histories and generated builds are
excluded. No recursive submodule initialization is needed for this snapshot.
